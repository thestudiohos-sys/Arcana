# Arcana by H.O.S Workspace Rules & Guidelines

- **Product Definition File**: Refer to [`PRODUCT_PRINCIPLES.md`](file:///d:/ArcanaByHOS/PRODUCT_PRINCIPLES.md) in the workspace root for all feature development, UI changes, prompt engineering, and API design.
- **Non-Negotiables**:
  1. ARCANA Free Reading uses **1 card**, Premium Deep Reading uses **3 cards** (Card 1: Current flow, Card 2: Hidden meaning, Card 3: Message to carry forward).
  2. Free reading must be a self-contained, comforting, reflective, and completed experience (never a paywalled teaser).
  3. Paid features (Deep Reading, Lucky Numbers, Digital Talisman) are optional rituals, NOT fear-based upsells.
  4. Both EN and KO languages MUST be supported seamlessly.
  5. 0 cost & commercial readiness principle: No paid external APIs during local frontend/mock development stages; prioritize commercially usable assets.
